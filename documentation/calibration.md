# Calibration and Thermal Measurement Notes

This document will contain calibration procedures and measurement assumptions as the project develops.

Topics to document:

- MLX90640 configuration and refresh rate.
- Sensor ambient/environment assumptions.
- Emissivity considerations for different materials.
- Frame averaging and filtering.
- Temperature range selection for visualization.
- Validation against a reference thermometer or known-temperature target.

The displayed thermal image is a visualization of infrared measurements; it should not automatically be treated as a calibrated contact-temperature measurement for every surface.
